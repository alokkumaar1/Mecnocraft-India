# Mecnocraft India — Website

Premium, dark-mode marketing site built with:

- React + Vite
- Tailwind CSS (v4)
- Framer Motion

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
